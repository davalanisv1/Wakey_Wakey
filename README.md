# Wakey Wakey!

Wakey Wakey! Is a blare alarm made by David Alanis to complete the "Blare!" Mission from the Stardance Challenge, it was fun, and helped me learn PCB design through KiCad.

## Components Used:
- 1x Seeed XIAO ESP32C3
- 4x MX-Style Keyboard Switches
- 4x White Blank DSA Keycaps
- 4x Through-Hole 1N4148 Diodes
- 1x 2.25in TFT Screen
- 1x 3.3V Piezo Buzzer
- 1x 2.54mm 8 Pin Male Header
- 8x 20cm Female-Female Jumper Wires
- 8x M3x5x4 Heatset Inserts
- 4x M3x8mm Screws
- 4x M3x16mm Screws
